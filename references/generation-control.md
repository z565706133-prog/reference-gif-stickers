# 付费生成控制

本Skill不会授权任何付费请求。用户明确说“只检查、免费、先给方案”时禁止生成，包括验证参数的试生成。

调用前查看当前官方开发文档及可用工具，确认实际模型名、接口、输入方式、尺寸、透明背景、输出格式和帧数参数。历史项目曾用Sunburst不代表其他用户或当前账户可用，也不代表标准Images接口支持原生GIF。不支持参数、模型不可用或文档不明确时停下说明，不发送付费探测，不静默换模型/输出形式。

费用根据核实的当前价目、尺寸/质量、参考图输入和请求数估算，标币种、估算日期和不确定项。未知价目就明确未知，不虚构精确金额。按响应usage保留估算，实际扣费以账单为准。

允许整批一次授权：记录每张上限、全批上限、允许模型和用途。上限不是必须用完的配额；成功后不继续抽卡。除用户另有说明，不自动重试、不切换模型。请求发送前写入不可覆盖的attempt记录并计入上限；超时、网络错误、未知响应也保留一次尝试，可能已计费，不能当作零次重发。额度用尽需新授权。

密钥仅通过本地环境变量或安全凭据存储取得。不要求粘贴到聊天，不保存进项目/分享包，不打印Authorization头、完整环境或秘密。检查只输出是否存在。生成与本地处理程序分离，dry-run不得触发网络生成。

每次保存请求参数（去除秘密）、参考图哈希、提示词、模型/接口、attempt编号、原始响应/原始图、usage及错误状态。不要把未知账单填0。保存审批状态和已消费次数，避免续作/压缩上下文后重复调用。
